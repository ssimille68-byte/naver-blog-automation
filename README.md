# 네이버 블로그 자동화

관심 분야만 입력하면 **글감 수집 → AI 글쓰기 → 이미지 선별 → 네이버 자동 발행**까지 이어지는 로컬 대시보드입니다.

AI 호출은 전부 Claude Code CLI 의 `-p`(print) 모드로 나가기 때문에, **API 키 없이 이미 쓰고 있는 구독 요금제가 그대로 적용**됩니다.

```
관심 분야  →  키워드 확장  →  네이버 뉴스·인기 블로그 수집  →  글감 후보 + 점수
                                                                    ↓
      네이버 블로그 발행  ←  이미지 AI 검증  ←  이미지 검색  ←  AI 블로그 글 작성
```

## 무엇을 해 주나

| 단계 | 하는 일 |
|---|---|
| **글감 찾기** | 관심 분야를 검색 키워드 5개로 넓히고, 네이버 뉴스(최신순)와 인기 블로그 글을 긁어 옵니다. AI 가 이를 읽고 글감 후보를 점수·근거와 함께 제안합니다. |
| **글쓰기** | 고른 글감의 원문을 실제로 열어 본문을 읽고, 내용을 이해한 뒤 **자기 문장으로 다시 씁니다.** 소제목·문단·목록·인용구로 나뉜 블록 구조로 출력합니다. |
| **이미지** | 글의 각 자리에 맞는 사진을 검색해 내려받고, **Claude 가 사진을 직접 눈으로 확인**해 맥락 적합성·품질·안전성을 0~100 점으로 매깁니다. 기준 점수를 넘지 못하면 본문에서 뺍니다. |
| **발행** | Playwright 로 스마트에디터 ONE 을 조작해 제목·본문·이미지·캡션을 넣고, 카테고리/공개범위/태그를 설정한 뒤 발행합니다. 소제목·목록·인용구 서식이 그대로 살아 있습니다. |

## 업데이트

```bash
npm run update     # 최신 코드로 갱신 (git 없이도 동작)
```

`node_modules` 와 `data/`(로그인 세션·초안)는 건드리지 않으므로 다시 설치할 필요가 없습니다.
직접 고친 파일이 있다면 덮어쓰이니 주의하세요.

진단 리포트(`capture-report.md`) 맨 위에 **코드 버전**이 찍힙니다.
결과가 이전과 똑같다면 코드가 갱신되지 않은 것은 아닌지 먼저 확인하세요.

## 설치

```bash
git clone <이 저장소>
cd naver-blog-automation

npm install
npm run setup     # Playwright Chromium 내려받기

# Claude Code CLI 가 없다면
npm i -g @anthropic-ai/claude-code
claude login      # 구독 계정으로 로그인 — 이 로그인이 그대로 쓰입니다

npm run doctor    # 환경 점검
npm start         # http://127.0.0.1:4300
```

> 📖 단계별 사용법과 실전 요령은 **[사용법.md](사용법.md)** 에 정리해 두었습니다.

## 쓰는 순서

1. **네이버 로그인** — 대시보드의 `네이버 로그인` 버튼을 누르면 **실제 브라우저 창이 열립니다.** 아이디·비밀번호·2단계 인증·캡차를 평소처럼 직접 입력하세요. 로그인이 확인되면 세션이 `data/browser-profile/` 에 저장되고, 이후에는 다시 로그인할 필요가 없습니다.
2. **글감 찾기** — 관심 분야를 입력하고 `글감 찾기`. 점수순으로 후보가 나옵니다. `근거 자료 보기`로 어떤 뉴스·블로그를 참고했는지 확인할 수 있습니다.
3. **글 쓰기** — 마음에 드는 글감에서 `이 글감으로 쓰기`. 추가 요청사항을 적을 수 있습니다.
4. **검토** — `초안` 탭에서 완성된 글과 **AI 이미지 검증 결과**(점수·사진 설명·판단 이유)를 확인합니다. 마음에 안 들면 `AI 수정 요청` 이나 `이미지 다시 찾기`.
5. **발행** — `발행 연습`으로 에디터에 채워지는 모습만 먼저 확인한 뒤, `네이버에 발행`.

`자동 실행` 탭에서 1~5 를 한 번에 돌릴 수도 있습니다.

## 로그인 세션은 어디에 저장되나

| 경로 | 내용 |
|---|---|
| `data/browser-profile/` | 실제 브라우저 프로필. 쿠키·로컬스토리지가 여기 담기며, 발행할 때 이 프로필을 그대로 재사용합니다. |
| `data/naver-session.json` | 확인용 쿠키 사본과 로그인 상태 기록. |

둘 다 `data/` 안에 있고 `.gitignore` 로 제외되어 있습니다. **다른 곳으로 전송되지 않습니다.** 로그아웃 버튼을 누르면 프로필까지 통째로 삭제됩니다.

## 설정

`설정` 탭에서 바꿀 수 있는 것들:

- **모델** — 글쓰기/이미지 판독에 쓸 모델 (`sonnet`·`opus`·`haiku`)
- **글의 톤, 목표 분량**
- **수집량** — 키워드당 뉴스·블로그 수, 글 1편당 참고할 원문 수
- **이미지** — 글당 이미지 수, 자리당 후보 수, **AI 합격 점수**(기본 70점)
- **이미지 검색 소스** — `openverse`·`wikimedia` 는 키 없이 바로 쓸 수 있고, `unsplash`·`pexels` 는 무료 API 키를 넣으면 추가됩니다
- **발행 시 브라우저 숨기기** — 끄면 발행 과정을 눈으로 볼 수 있습니다
- **조작 간 지연** — 너무 빠르면 네이버가 입력을 놓칩니다. 100~200ms 권장

환경 변수는 `.env.example` 를 참고하세요.

## 윈도우에서 돌릴 때

윈도우도 그대로 지원합니다. 다만 두 가지만 권합니다.

- **폴더를 OneDrive 밖, 짧은 경로에 두세요.** 예: `C:\naver-blog`
  OneDrive 는 파일을 계속 동기화해서 브라우저 프로필·이미지 파일과 충돌할 수 있고,
  경로가 길면 윈도우의 260자 제한에 걸려 설치가 실패할 수 있습니다.
- 명령은 **명령 프롬프트(cmd)** 나 **PowerShell** 어디서 실행해도 됩니다.

## 리눅스 서버에서 돌릴 때

네이버 로그인 창은 화면이 있어야 뜹니다. 디스플레이가 없는 서버라면:

```bash
sudo apt install xvfb
xvfb-run -a npm start
```

발행 자체는 헤드리스로 돌아가므로 로그인만 한 번 해 두면 됩니다.

## 테스트

```bash
npm test      # 전체 (네트워크 없이 동작)
npm run capture   # 실제 네이버 HTML 을 받아 파서 검증 + 픽스처 저장
```

`npm test` 는 네트워크 없이 두 가지를 검증합니다.

- **발행 자동화** — **스마트에디터 ONE 을 흉내 낸 로컬 모의 페이지**(`test/fixtures/editor.html`)를 상대로 iframe 탐지 · 팝업 닫기 · 제목/본문 입력 · 서식 붙여넣기 · 이미지 업로드 · 캡션 · 발행 레이어 · 게시글 URL 회수까지 확인합니다.
- **검색 결과 파싱** — 마크업 세대별 표본(구형 레이아웃, 신형 `sds-comps` 레이아웃, 미지의 구조, 광고·중복·연관검색어 잡음)을 상대로 각 분기가 제대로 도는지 확인합니다.

```bash
node test/mock-server.js   # 모의 에디터를 브라우저로 직접 열어 보기
```

### 실제 네이버 HTML 로 파서 확인하기

표본 테스트는 "파서가 다루기로 한 구조"만 검증합니다. **실제 네이버가 지금 내려보내는 HTML** 로 확인하려면:

```bash
npm run capture                                # 기본 키워드
npm run capture -- "홈카페 원두" "러닝 입문"     # 키워드 지정
npm run capture -- --no-save                   # HTML 저장 없이 확인만
npm run capture -- --from <파일.html>           # 저장해 둔 HTML 재진단 (네트워크 불필요)
```

하는 일:

- 실제 검색 페이지를 열어 파서를 돌리고 **몇 건을 뽑았는지 / 어떤 카드 선택자가 적중했는지 / 어떤 필드가 통째로 비었는지** 보고합니다
- 제목만 건지고 요약·출처·날짜가 전부 비면 **성공이 아니라 "부분 성공"으로 표시**합니다 (글감 판단이 불가능하므로)
- 문제가 있으면 **기사 링크의 조상 사슬**과 **결과 영역 DOM 골격**을 함께 덤프합니다. 이것만 보면 새 선택자를 바로 쓸 수 있습니다
- 자동화 차단 페이지, "검색결과 없음", 빈 페이지도 구분해서 알려 줍니다
- 전체 내용을 `capture-report.md` 로 저장합니다

**결과가 이상하면 `capture-report.md` 를 그대로 복사해서 물어보세요.** 그 안에 선택자를 고치는 데 필요한 정보가 전부 들어 있습니다.

캡처된 HTML 과 리포트는 `.gitignore` 에 있습니다. 특정 캡처본을 회귀 테스트로 저장소에 남기고 싶다면 `git add -f test/fixtures/naver/news-....html` 로 강제 추가하세요.

## 네이버가 화면을 바꿨을 때

네이버는 검색 결과와 에디터 DOM 을 자주 바꿉니다. 에디터 클래스명은 해시까지 붙어 있고(`publish_btn__m9KHH`) 배포마다 달라집니다.

그래서 **선택자는 전부 `server/naver/selectors.js` 한 파일에 후보 배열로 모여 있습니다.** 에디터는 접두사 부분 일치와 텍스트 매칭을, 검색은 세대별 카드 선택자와 링크 패턴 폴백을 함께 씁니다.

깨졌을 때 고치는 순서:

| 증상 | 할 일 |
|---|---|
| 글감 수집이 0건 | `npm run capture` → 리포트의 조상 사슬·DOM 골격 확인 → `SEARCH` 수정 → `npm test` |
| 요약·언론사·날짜만 빈칸 | 같은 리포트의 "비어 있는 필드" 경고와 DOM 골격 확인 → 해당 필드 선택자만 수정 |
| 발행이 실패 | `data/logs/` 의 화면 캡처 확인 → `SEL` 수정 → `npm test` |

## 구조

```
server/
  ai/claude-cli.js        `claude -p` 래퍼 (동시 실행 제한, JSON 파싱, 재시도)
  browser.js              Playwright 관리, Chromium 자동 설치, 프로필 잠금
  collect/
    naver-search.js       네이버 뉴스·블로그 검색 수집
    extractors.js         검색 결과 카드 파서 (브라우저 안에서 실행, 저장된 HTML 로도 검증 가능)
    diagnose.js           DOM 골격·조상 사슬 덤프 (선택자가 깨졌을 때 진단용)
    article.js            기사·포스트 본문 추출
  pipeline/
    topics.js             키워드 확장 → 수집 → 글감 후보 생성
    writer.js             원문 읽기 → 블록 구조 글 작성 / 수정
    image-search.js       Openverse·Wikimedia·Unsplash·Pexels
    images.js             다운로드 → AI 시각 검증 → 최고점 선택
  naver/
    session.js            로그인 창 띄우기, 세션 저장·확인·삭제
    selectors.js          검색·에디터 DOM 선택자 (깨지면 여기만 수정)
    format.js             블록 → 에디터용 HTML / 미리보기
    publisher.js          에디터 조작 및 발행
  routes/api.js           REST API + SSE
  jobs.js                 백그라운드 작업 큐
scripts/
  capture-naver.js        실제 네이버 HTML 캡처 + 파서 검증
  doctor.js               환경 점검
public/                   대시보드 (빌드 도구 없는 순수 HTML/CSS/JS)
test/                     모의 에디터 기반 발행 테스트 + 검색 파서 테스트
```

## 알아 두면 좋은 것

- **발행 전에 꼭 읽어 보세요.** AI 가 쓴 글은 사실관계가 틀릴 수 있습니다. `발행 연습` 모드를 먼저 쓰는 걸 권합니다.
- **네이버 이용약관.** 자동화 도구로 대량·반복 발행을 하면 계정이 제재될 수 있습니다. 하루 1~2편 수준의 개인 블로그 운영 보조 용도로 쓰세요.
- **이미지 저작권.** 기본 검색 소스는 자유 이용 라이선스 위주지만, 라이선스 표기가 필요한 경우가 있습니다. 초안 화면에 출처가 함께 표시되니 확인하세요.
- **AI 는 이미지를 실제로 봅니다.** 검색어만 믿고 넣지 않고, 내려받은 파일을 Claude 가 직접 열어 확인한 뒤 점수를 매깁니다. 기준 미달이면 본문에서 빠집니다.
